# 武器リスト

文書種別: **説明文書**
参照正本: [`class_reference.md`](class_reference.md)、[`character_progression.md`](character_progression.md)、
[`base_development.md`](base_development.md)、`data/weapons.json`

`data/weapons.json`と戦闘処理を優先する。

| 槍兵 | 長槍 / 重槍 / 迎撃槍 | 長射程、重火力+押し出し、防御姿勢 |

| 旗手 | 遠征旗槍 / 勇壮旗槍 / 守護旗槍 | 支援範囲、火力支援、防御支援 |

## 注意

- 武器名だけだと効果が分かりにくいものは、UIで特徴文を併記する。
- 分岐武器は「威力違い」だけでなく、移動、押し出し、状態異常、支援の差を見せる。
