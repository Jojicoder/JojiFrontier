# スキルリスト

文書種別: **説明文書**
参照正本: [`skill_system.md`](skill_system.md)、[`initial_skill_effects.md`](initial_skill_effects.md)、
`src/core/Skill.cpp`

この文書は、装備スキルを一覧で確認するための説明文書である。実際の使用可否、回数、効果処理は
`Skill.cpp`と戦闘処理を優先する。

## 使用区分

| 区分 | 意味 |
|---|---|
| 能動 | プレイヤーが選んで使う |
| 受動 | 条件を満たすと自動で効く |
| 反応 | 敵行動などに反応して自動発動する |
