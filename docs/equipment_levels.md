# 武器/防具Lv1〜20 要求素材一覧

武器/防具のLv1〜20強化に必要な素材と、どのあたりの攻略段階を想定しているかをまとめた
一般ドキュメント。全12兵種・全地域が同じ式・同じLv刻みで動く(`weaponLevelUpCost()`/
`armorLevelUpCost()`、`WeaponLeveling.hpp`/`ArmorLeveling.hpp`)が、素材IDだけが兵種ごとに
変わる(`weaponLevelMaterialsByClass()`/`armorLevelMaterialsByClass()`)。
深層/最深層(Lv6以降)は、実際のダンジョン戦闘・ボスまで実装済みなのは灰枝の森
(AshboughForest/FrontierScout)のみだが、Lv6〜20の強化コスト計算自体は`data/deep_layers.json`
に登録済みの全12兵種で動く(残り11兵種の深層地域は素材idのみ登録、戦闘コンテンツは未実装 -
`docs/material_list.md`「深層限定素材」参照)。以下は全12兵種分の実測値。
数量・素材構成の正本は`docs/deep_layers.md`・`docs/character_progression.md`。

## 想定コンテンツとの対応

| Lv帯 | 想定コンテンツ |
|---|---|
| Lv1 | 製作直後(加入直後の初期装備) |
| Lv2〜5 | 本編10地域・全62地点の通常素材だけで強化できる範囲。本編クリアの基準はこの帯 |
| Lv6〜9 | 深層前半５地域まで |
| Lv10〜13 | 深層後半5地域の素材要求　地図外苑攻略後撃破まで |
| Lv14〜20 | 最深層10地域の素材要求　地図外苑攻略後Lv20に到達可能 |

**本来の設計はこの表のとおり「地域数」ベース**(Lv9=深層前半5地域クリア、Lv13=深層後半5
地域クリア・地図外苑(MappedEdge)攻略後、Lv20=最深層10地域クリア・地図外苑攻略後)。

**現状のコード(`weaponDeepLevelUpCost()`)はこの設計をまだ実現できていない。** 深層/最深層の
実際のダンジョン(戦闘・敵配置・ボス)は灰枝の森1地域しか実装されていないため、Lv9/13/20は
「本来必要な地域数」の代わりに、各兵種自身の所属地域が持つ深層内1体目ボス・深層内2体目ボス
(深層完了)・最深層ボス(最終)の撃破限定素材を要求する暫定コードになっている(下表の★)。
素材id自体は全12兵種分が`data/deep_layers.json`に登録済みだが、これは仮の代替実装であって、
「地域数」を数える仕組み自体はまだ存在しない。他地域の横展開(実際のダンジョン実装)時に、
Lv9/13/20のゲート条件を「クリア済み深層地域数」を実際に数える形へ書き換える必要がある
(具体的な地域数の数え方・地図外苑の扱いは横展開時に確定)。それ以外のLv(★のつかない段)は、
共通素材(本編は地域固有の通常素材、深層以降は各兵種自身の地域の深層核)だけで積み上げられる
点は設計どおり。

## 備考

- Lv6以降は武器・防具ともまったく同じ式(`weaponDeepLevelUpCost()`を防具側も再利用)。
  「防具はLv6以降、武器と異なる伸び方にする」という区別は設けていない。全12兵種とも
  Lv6〜20の共通深層素材(`<地域>_deep_core`)合計は135個で揃う(式が兵種共通のため)。
- 各兵種の共通深層素材は、その兵種の所属地域の深層/最深層のどの戦闘でも入手できる想定
  (戦闘を重ねるほど1回あたりの入手量が増える)。実際の入手経路が実装済みなのは灰枝の森
  (`docs/regions/ashbough_forest_bestiary.md`の戦闘別報酬表を参照)のみで、残り9地域は
  素材idの登録のみ(戦闘・敵配置は未実装)。135個は「1回クリアすれば揃う量」ではなく、
  複数周回を前提にした量。
- ボス素材3種(Lv9/13/20)はそれぞれ対応するボスを撃破しないと入手できないユニーク素材で、
  代用不可。全10地域分の素材id一覧は`docs/material_list.md`「深層限定素材」参照。
- 2026-08-01、「Lv6〜20にも他地域の深層素材を少量混ぜる」方針を実装済み
  (`docs/deep_layers.md`「他地域深層素材の混合要求」、`docs/prompts/
  equipment_other_region_materials_prompt.md`)。ボス撃破チェックポイントでは
  ないLv8/Lv11/Lv17に、全兵種共通で自地域とは異なる他地域の深層共通素材を
  少量(1〜2個)追加要求する(上表の「他地域素材を追加混合」の行)。この3つの
  Lvは兵種ごとに異なる3つの他地域を使い、同じ他地域を2回使わない。
