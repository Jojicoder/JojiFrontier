- 人間敵は必ず死亡扱いにせず、撤退/降伏/退避を扱う。

## 拡張候補メモ

状態: ユーザー提示案をもとにした記録。確定仕様ではない。地域別正本へ反映する場合は、
各地域ファイル、`enemy_ai_rules.md`、`boss_common_rules.md`へ役割と処理を整理する。

### 全体方針

3x8盤面では、敵1体の射程や範囲攻撃を強くしすぎると逃げ場がなくなる。そのため、敵の強さは
次の要素で作る。

- 次の行動が視覚的に分かる予告
- 地形や装置を使った位置取り
- 撃破以外の対処法: 遮断、阻止、護衛、奪取、降伏
- 敵同士の組み合わせ
- Objectiveを放置した場合の不利益

通常敵は明確な能力1つ、特殊敵は2つ程度に絞る。Bossは攻撃力よりも「予告行動をどう止めるか」
を攻略の中心にする。

### 優先して採用したい敵役割

| 役割 | 候補例 | 採用理由 |
|---|---|---|
| 伝令/逃走役 | `signal_runner`、`plateau_runner`、`supply_bearer` | 撃破以外に進路封鎖や足止めの価値を作れる |
| 装置操作役 | `watch_lamplighter`、`sluice_raider`、`vent_opener`、`gate_winchman` | 地形/Object/Objectiveと連動しやすい |
| 運搬/奪取役 | `settlement_looter`、`relic_pilferer`、`boundary_scavenger` | 荷物、防衛、奪還Objectiveに使える |
| 予告射撃/予告範囲 | `fort_crossbowman`、`blast_charge_layer`、`path_eraser` | 理不尽さを抑えながら盤面圧を作れる |
| 支援/士気役 | `field_standard_bearer`、`alarm_keeper`、`wind_banner_guard` | 敵編成全体の構造を崩す遊びを作れる |

### 既存敵との整理

| 既存敵 | 扱い |
|---|---|
| `Bandit` | 完全廃止せず、人間雑兵AIの基底テンプレートにする。表示名と特殊行動は地域別に変える |
| `Wolf` | 灰枝の森序盤に限定し、後半地域で同じ狼を反復しない |
| `AshenhornBoar` | 灰枝の森Bossとして維持。新規の群れ主系Bossとは役割重複に注意 |
| `AshironGrubworm` | 採石場Boss/強敵として維持。潜行と崩落の予告を強める |
| `MarshFangSerpent` | 黒水低湿地の代表敵として維持。毒と水地形連動を強める |
| `PlateauCourierCaptain` | 逃走型Bossとして強化 |
| `RaidLeader` | 指揮・撤退Bossとして強化 |
| `RedbackLizard` | 熱地形Bossとして強化 |
| `SanctumRetrievalLeader` | 聖遺物回収競争型Bossとして強化 |
| `FortGarrisonCaptain` | 号令Bossとして強化 |
| `FrontierBeast` | 地図外縁の最終Boss候補として維持 |

### 実装時の注意

- `brush_stalker`のような「標的にされにくい」隠密効果はUIで分かりにくいため、強くしすぎない。
- `echo_beast`の模倣は面白いが実装負荷が高いので後回し。
- 地図外縁の端移動や列消失は事故りやすいため、必ず予告付きにする。
- 「弱点: 炎」のような属性が現行に薄い場合は、弱点ではなく「対処法」として書く。
- 最初は各地域2〜3種ずつ、共通AI 8〜10個で増やす。70種を一度に実装しない。
