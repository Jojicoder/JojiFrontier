## 地形/盤面要素

| 要素 | 主な地域 | 役割 |
|---|---|---|
| 茂み | 灰枝の森など | 回避を上げ、獣/斥候の位置取りに影響 |
| 浅瀬 | 灰枝の森、黒水低湿地 | 移動コストを増やし、ルート選択を作る |
| 灰地 | 灰枝の森など | 移動ペナルティ。斥候は扱いやすい |
| 薬草地点 | 灰枝の森、黒水低湿地 | 行動終了で回復/採取。副目標にもなる |
| 倒木/障害物 | 灰枝の森、採石場、砦 | Boss誘導、通路制御、工兵/重装兵の価値 |
| 装置/弁/信号機 | 監視所群、峡谷、聖堂、砦 | OperateObject系Objective |
| 護衛/避難対象 | 高原、集落、聖堂 | 敵全滅以外の勝利条件を作る |
| 増援口 | 砦など | 防衛、封鎖、持久戦の圧力 |

## 既知の見直しポイント

- 視覚的なRoute Mapがまだ弱く、分岐構造が画面で分かりにくい。
- 深層ルート選択は最初だけにし、遠征中は固定する改善候補がある。
- OperateObjectや脱出系ObjectiveはUI誘導と自動テストが不足しやすい。
- 地域ごとのterrainProfile使い回しが多く、マップ差が薄く見える箇所がある。
