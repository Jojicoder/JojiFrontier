# 防具リスト

文書種別: **説明文書**
参照正本: [`character_progression.md`](character_progression.md)、[`deep_layers.md`](deep_layers.md)、
`include/jf/core/Armor.hpp`

この文書は、防具の見比べ用リストである。防具の実効果は`Armor.hpp`を優先する。

## 共通ルール

| Tier | 方向性 | Lv1補正の基準 | Lv成長 |
|---|---|---|---|
| Tier1 | バランス型 | DEF+1 / RES+1 | DEF/RESを交互に伸ばす |
| Tier2 | DEF特化 | DEF+2 / RES+0 | DEFだけ伸ばす |
| Tier3 | RES寄り | DEF+1 / RES+2 | DEF/RESを交互に伸ばす |

例外:

- 古参守備兵、槍兵、重装兵のTier2はDEF+3。
- 暁の衛生兵、旗手、戦闘魔導士のTier3はRES+3。
- Tier3の「状態異常耐性」風味は記録済みだが、現行実装ではDEF/RES補正のみ。
