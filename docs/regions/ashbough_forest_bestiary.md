# 灰枝の森: 敵リスト・素材一覧

本編(`docs/regions/ashbough_forest.md`が正本)と深層/最深層(`docs/deep_layers.md`が正本)の
両方について、実装済みの敵編成と各戦闘で得られる素材を一覧化した参照用ドキュメント。
数値・仕様の正本はそれぞれのリンク先。本書は実装済みコード(`src/core/Region.cpp`)の
現状スナップショットで、内容が食い違った場合はコードとリンク先の設計書を優先する。

## 深層/最深層(`docs/deep_layers.md`、灰枝の森プロトタイプのみ実装済み)

深層・最深層はRouteGraphを持たない単純な連続戦闘(深層=4戦、最深層=2戦)。地形は本編の
「折れ木の縄張り」(`brokenwood_territory`)を再利用し、敵は本編の狼・灰角大猪をリスキン
流用している(新規UnitClassは追加していない)。敵ステータスは本編の狼/灰角大猪の基礎値へ
`DeepLayerScaling.hpp`の倍率を掛けたもの(2026-08-01時点の倍率は下表)。

| 戦闘 | 敵編成 | 報酬 |

| 最深層・戦闘2(最終ボス「朽木の王」) | 灰角大猪の古老「朽木の王」 | 灰枝深層核×5、灰角深遺物×1 |

灰枝深層核は共通素材(戦闘を重ねるほど入手量が増える)、灰角深牙/灰角深角/灰角深遺物はボス撃破限定の
ユニーク素材(他のボス・他地域では代用不可)。これらは武器/防具Lv6〜20の強化専用材料で、
Lv9は灰角深牙、Lv13は灰角深角、Lv20は灰角深遺物がそれぞれ「追加で1個」必要になる
(`weaponDeepLevelUpCost()`/`armorDeepLevelUpCost()`)。

**注意**: ボス素材はLv到達の**必要条件の一つ**であって、それだけでLvが上がるわけではない。
灰枝深層核はLvごとに`2 + (targetLevel - 6)`個要求され、Lv6→20を通しで積むと**合計135個**
必要になる(深層1周では最大でも数個〜十数個しか得られないため、複数周回が前提)。「朽木の王を
1回倒せばLv20にできる」わけではなく、深層/最深層の周回で灰枝深層核を積み増しながら、各
チェックポイントのボス素材を揃えていく設計。また拠点Lv15(中継拠点)/Lv20(最奥拠点)
昇格のコストにも灰枝深層核を使う(`BaseState::outpostLevelCheckpoints()`)。

**注意(本来の設計との差分)**: Lv9/13/20を「灰枝の森自身のボス撃破」で判定しているのは
灰枝の森1地域しか深層が実装されていない現状の暫定コード。本来の設計はLv9/13/20を
「クリア済み深層地域数」ベースで判定する(詳細は
`docs/equipment_levels.md`「想定コンテンツとの対応」/
`docs/deep_layers.md`「Lv帯と対応コンテンツ」参照)。
